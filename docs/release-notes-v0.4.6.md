# MIXED-API v0.4.6

- 修复 AIS 初始化真正发出“MIXED connection initialization”、模型长时间思考、必须手动停止才能继续的问题：捕获页面会话服务后立即结束初始化；额外安装当前受控标签页的浏览器网络拦截，覆盖页面提前缓存的 fetch/XHR。初始化不产生模型回复、不消耗生成额度。初始化取消或超时后保留拦截，直到有效新请求或关闭该标签页。
- WorkBuddy 改为读取所选站点 `/v3/config` 的实时模型和积分倍率。国际 WorkBuddy AI 的 `deepseek-v4.1-flash` 在当前目录声明零倍率时显示“当前目录零积分”；活动改价后重新读取就更新标记。收费、未声明费用分别显示，不凭模型名字猜免费，不把旧快照当实时结果。实际推理权限仍由当前账号决定。
- Build 工具声明使用原生 `parametersJsonSchema`，保留 `$defs`、`$ref` 等完整 JSON Schema；Playground 对工具及结构化输出展开有界本地引用。远程引用、循环引用和冲突约束明确拒绝，不删除约束后报成功。
- 无头V改为“匿名连接”，准备后自动打开连接。**无需 Google 账号、Cookie 或 Express Key**。它使用官方匿名请求和浏览器官方验证环境，不是 AIS 的账号授权流程。

## 更新

退出旧版，保留 `mixed-api.json`，运行新版。**在 `edge://extensions` 或 `chrome://extensions` 刷新“MIXED 浏览器连接”**：本版新增官方 RPC 域名权限和网络拦截权限。再从软件重新打开 AIS 官方页面。只换 EXE 不刷新扩展，旧后台脚本不会获得修复。此前已开始的初始化生成须在旧页面停止后重新连接。

WorkBuddy 在账号步骤先选正确站点，再检查模型。免费活动由服务方调整，以每次读取到的积分倍率为准；目录接口失败会显示错误，不悄悄展示旧免费价格。软件标记零倍率不等于已实测该账号成功生成。积分不足、限流及账号权限仍需分别检查。

无头V不要求登录Google；浏览器连接扩展与网络仍须正常。若官方匿名验证失败，按具体网络或验证提示处理，不通过重新登录账号“修复”。快速V仍单独需要 Express Key，AIS仍使用本人Google账号。

## 本轮验收

Go公共HTTP回归覆盖实时站点模型/费用更新、活动由零倍率改为收费、禁用模型过滤、Build与Playground工具/响应Schema、本地循环引用拒绝、无头V无登录提示。页面脚本覆盖缓存fetch初始化不得外发、捕获服务后立即就绪；扩展回归覆盖网络拦截安装和取消后拒绝请求不得解除拦截。实际独立Chromium测试确认DNR规则被接受，并在网络出站前以ERR_BLOCKED_BY_CLIENT阻断初始化生成。个人Google账号真实生成仍未验收。
