## Standards

- 安装准备提前启用来源：已修复，凭证准备不再设置 Enabled；新增 HTTP 安装夹具测试验证下载、生成配置后来源仍关闭且未执行。

- 别名对模型命名规则的例外未有领域文档：已补 ADR-0002、词汇表与 AGENTS 规则。

复查未发现新的已确认权限、凭证隔离或生命周期阻断问题。状态字符串可进一步改为结构化状态，属于后续设计改进，不影响本版已覆盖的三步门控。

## Spec

- 官方无头V首次规则需要交互，但原启动方式没有输入窗口：已将无头V的同源运行组件统一到真实交互启动路径，不代替用户确认。
- 准备提前启用、旧模型误判：同上修复。
- 手动连接出错后无法返回编辑：增加返回上一步，浏览器回归覆盖。
- 重新打开完成页时没有连接信息：明确要求重新检查后展示当前模型与统一连接信息，避免空白“已完成”。

复查确认没有额外本地来源或运行版本选择。文档已改为新版大字号工作台、独立 /admin 和维护组件入口。
