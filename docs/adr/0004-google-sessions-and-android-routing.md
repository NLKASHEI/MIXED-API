# ADR-0004：官方页面会话与 Android 明确路由

状态：Accepted，2026-10-17。开发实现与验证范围见 integration-progress.md；不代表正式版已发布。

AIS 的 Build 和 Playground 使用同一来源的隔离官方页面会话，协议转换、模型目录和请求生命周期由 Go/Java 核心实现。无头V使用自己的隔离官方页面会话。授权窗口中没有管理接口桥梁，不接收任意脚本或任意出站 URL。只有用户亲自完成登录、规则确认、挑战和首次测试消息；应用观察成功结果后才标记会话就绪。模型目录可读仍不等于代理生成已实测。

Windows 来源会话使用随 EXE 提供的渲染器及独立 profile；Android 使用系统 WebView 的独立 profile，需支持 MULTI_PROFILE 与 DOCUMENT_START_SCRIPT。能力不足时禁用对应入口并提示更新系统 WebView。系统 WebView 是平台依赖，不以其存在来声称 APK 内嵌完整浏览器运行时。

每个来源会话在完整响应期间只允许一个活跃请求。取消关闭原始 fetch，读取队列有界并由消费速度控制；不在生成中断后自动重放。仅可按用户设置重试生成前的 HTTP 429/503，尊重 Retry-After；时限、重试与聚合设置存储在共享 engine_settings 结构中。

为保持 AGENTS 的明确来源边界，Android 电脑桥接统一枚举和接收 `pc/电脑原始模型ID`，替代 ADR-0002 中直接枚举电脑原始 ID 的规则。别名仍显式绑定该完整目标。指定来源不存在或未启用时返回错误，不自动改投电脑。旧客户端需重新读取模型目录或配置显式别名。

兼容保留旧 command/workdir 字段，不执行它们。准备内置来源时清除旧凭证与命令；切换模式会先关闭来源。外部程序启动和 EXE 导入接口退役。
