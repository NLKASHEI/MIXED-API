# ADR-0006：默认浏览器与连接验收

状态：Accepted，2026-10-17。根据 Windows v0.4.0 用户故障反馈，替代 ADR-0004 中的 Windows 来源窗口和手动测试消息要求。

Windows 主窗口继续是单 EXE 中的独立应用窗口。AIS、无头V的来源页面改为 Windows HTTPS 关联指定的默认浏览器，当前适配 Edge / Chrome。为建立受控的本机会话，启动 MIXED 独立 profile（配置文件旁的 browser-profiles）；不读取日常浏览器 profile，也不使用内嵌 WebView2 冒充默认浏览器。其他默认浏览器明确报不支持。启动和清理不弹控制台，仅结束完整 EXE 路径和专用 profile 都匹配的浏览器进程。

用户亲自处理登录、条款和验证。点击连接会话后，软件使用官方页面正常输入和提交入口初始化，捕获当前页面接口，拦截初始化请求，不把初始化文字提交到生成端点。若提交后的初始化取消或超时，旧页面保持阻断迟到的生成，需刷新后再连接；不会解除拦截后放出迟到请求。初始化不改写未发送的用户草稿，不点击条款、登录或挑战。

会话就绪仅表示传输材料已建立。模型目录成功、真实生成成功分别报告；配置页的测试对话经过公开 /v1/chat/completions，按用户所选模型请求，错误不能标为成功。每次测试固定模型，不在等待期间换成另一模型的成功提示。

无头V 官方页面已从 vertex-ai 跳转至 agent-platform/studio/multimodal，当前输入是 contenteditable role=textbox。仅完成未授权页面 DOM 核对和离线初始化测试，实际条款后初始化与真实生成尚未验收。AIS 同样需本人账号完成实际推理验收。

Android 沿用系统 WebView 隔离会话，不声称与 Windows 默认浏览器相同。共享初始化脚本和管理 HTML，初始化管理请求监测客户端断开，取消须确认或销毁旧页面后释放会话。

OpenCode 的来源固定版本清单用于区分免费无头候选、Key 付费、已停用、未知；access.verified 默认 false，清单不是当前账号或当前应用的可用性证明。未知模型不通过名称猜测免费，也不自动切换收费模型。
