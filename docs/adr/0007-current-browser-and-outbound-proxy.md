# ADR-0007：当前浏览器会话与出站代理

状态：Accepted，2026-10-17。根据用户实际故障反馈，替代 ADR-0006 的 Windows 专用浏览器 profile 决策。

Windows 通过 ShellExecute 打开本机连接页，使用当前默认 Edge / Chrome 的普通浏览器资料和现有账号。不再启动 CDP、不再传 user-data-dir，也不读取或解密日常浏览器的凭据数据库。EXE 内置连接扩展，按需释放到配置旁的 browser-extension；用户在自己的浏览器加载一次。升级扩展后按步骤刷新扩展和连接页。主应用仍为独立 EXE 窗口，无命令行窗口，无上游程序下载。

扩展仅有 scripting 和本机连接页、两个 Google 官方来源的域名权限。每个来源使用独立的 127.0.0.1 临时监听器及随机能力令牌；Host、扩展 Origin 和令牌同时校验。仅接受固定的会话命令，不提供远程 eval。扩展创建的来源标签页使用当前浏览器登录态，关闭连接时仅关闭该标签页；断线中止未完成生成。命令串行，取消不能抢在迟到的 start/initialize 前确认完成。Go 侧保留来源排队、输出背压与有界帧。

快速V等 Go 出站请求默认按 PROXY_URL、HTTP(S)代理环境变量、Windows 系统设置选择出口，支持手动 HTTP/HTTPS/SOCKS5 或显式直连。本机请求直连。系统配置最长 5 秒刷新，读取网络设置立即刷新。已选代理连接失败不自动直连。PAC 库无法区分解析失败和 DIRECT；若 PAC 没有给出可用代理则停止请求，由用户手动选择代理或直连。

浏览器会话使用浏览器自己的网络设置。应用内手动代理不改动用户浏览器设置；后台不得将 Go 的出口冒充浏览器实际出口。快速V项目/区域为可选且须成对填写，绑定当前 Key 的项目，官方域名保持固定。空值保留 Express 默认路由，不偷偷改区域。

后台记录请求编号、模型、脱敏目标、实际 Go 代理、连接地址、失败阶段、CONNECT 状态、上游状态/业务码和等待时间，不记录聊天、Cookie、Key 或完整上游异常。OpenCode 的所有模型列表仅保留当前目录与审阅免费清单的交集；付费、停用、未知费用不展示，也不自动切换付费模型。

Android 开发和发布按用户要求暂停；共享 HTML 保持同步，Windows 代理与区域配置入口在 Android 隐藏。Android 的实现差异继续明确记录。浏览器桥和协议测试不能替代本人 Google 账号实际生成验收。
