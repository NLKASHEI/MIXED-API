# ADR-0009：站点隔离、账号状态与可选断线续传

2026-10-18，已接受，Windows Go核心。

WorkBuddy仍是一个公开来源。国内、WorkBuddy AI国际、CodeBuddy国际为三个固定官方站点，凭据、刷新任务和授权轮询按私有站点槽位隔离；旧国内凭据路径保留。站点不可由令牌中的URL决定，不允许跨站回退。模型目录是候选而非账号授权证明。

AIS已有登录账号与协议材料就绪分别报告。使用当前官方页面自身凭据调用ListModels检查账号；不把Cookie、授权头发给本地管理界面。协议材料未加载不等于待过验证码；不得代替本人处理登录、同意或挑战。

快速V默认仍随客户端取消。只有显式启用resumable_enabled时，生成才与读取连接分离；开启前UI说明资源、取消和缓存行为。这是ADR-0001取消规则的明确可选例外，不影响其他来源。

续传仅适用于Chat流。同一客户端Key作用域中，相同Idempotency-Key和请求内容复用一次生成，不同内容返回409；无幂等键的请求各自生成。返回X-Mixed-Stream-ID，并提供带鉴权的GET/DELETE接口。SSE的id是零基事件序号，Last-Event-ID从后一条开始，resume_from/from为下一条序号。Key轮换隔离旧缓冲。缓存不落盘，不进入请求日志；过期但仍被读取的数据继续计入预算。关闭进程清理任务。

上游断流和下游断线不是一回事。前者只在内容交付前重试；完整缓存模式可隐藏失败尝试。后者读取同次生成的内存记录，不重新请求模型。Gemini长解码continuation token是另一项协议能力，本ADR不实现该能力。
