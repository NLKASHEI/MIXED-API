# ADR-0010：初始化网络拦截与实时费用目录

2026-10-18，已接受，补充ADR-0006/0008/0009。

AIS页面可提前缓存fetch，页面函数包装不构成可靠的网络阻断。初始化前须通过内置扩展安装仅作用于当前受控标签的DNR规则，阻断生成及自动保存。捕获snapshot服务后立即以AbortError结束初始化，不等待模型思考或实际生成。初始页面没有完成会话材料捕获时，不解除网络拦截；取消或超时后，拒绝的新请求也不得移除拦截。只有就绪页面接受有效MIXED请求时才能解除；失败则恢复，关闭标签删除对应规则。不扫描其他普通标签。扩展对RPC域的新增权限只用于该固定规则。

WorkBuddy实时模型目录与积分倍率按所选固定站点获取，不用静态快照认定免费。服务方明确声明数字零倍率时标记当期零积分；正数标记积分倍率，未知不猜测。每次刷新重新读取，错误显式返回。目录可读及零倍率均不是实际生成权限证明，不自动更换站点或模型。国内与国际产品按各自渠道获取目录，兼容User-Agent保留MIXED身份，不改动推理身份。

无头V是匿名来源，不要求Google账号授权或Express Key。界面使用匿名连接步骤，软件准备后自动打开连接。官方匿名验证环境仍依赖浏览器正常网络及SDK；与AIS本人账号授权分开报告。
