# ADR-0008：打开官方页面后自动连接

状态：Accepted，2026-10-17。根据用户要求，简化 ADR-0007 的 Windows 配置操作。

Windows 的“打开官方页面”仍由 ShellExecute 使用系统默认 Edge / Chrome 及当前资料目录。内置连接扩展已加载时，临时本机连接页完成配对后在原标签页跳转官方站点，不再多留连接页，也不要求用户回应用点击“连接会话”。首次加载扩展仍须由用户在浏览器授权；普通网页跳转不能取得跨站会话接口，不伪装为已连接或静默安装扩展。

EXE 等待官方页面给出可初始化状态，才自动准备来源。本人处理登录、条款和挑战；存在弹窗、草稿或执行中请求时等待，条件解除后继续。初始化时不向服务方提交测试生成。真正验证失败保留具体原因，需本人刷新官方页面后再检查；不无限重复官方验证。页面刷新后可自动重连，应用关闭或来源页面丢失则停止。

准备会话不自动启用来源、不证明真实推理。用户仍通过下一步启用并检查模型，可按所选模型执行一次明确的 API 测试。浏览器内请求继续使用浏览器代理；Go 手动代理不覆盖它。

连接能力令牌只用于回环配对，不放进官方页面 URL、脚本或请求。官方 URL 的 mixed-api-session 片段是公开的注入时机标记。扩展只操作自身连接的来源标签页，不扫描或读取其他普通页面。

Android 开发/发布仍暂停。共享脚本与 HTML 同步，Android 保留原手动“连接会话”入口；Windows 自动等待由 Go Browser 实现。

v0.4.4 生命周期修正：连接断开不是关闭本人登录页的授权。未执行生成时保留官方页，扩展在同一标签页做最多3次重连；Go保留10秒重连宽限。旧连接排队命令不得在新连接外发。存在无法确认取消的生成时，继续终止唯一受控来源页，不释放一个仍可生成的旧会话。普通非模态帮助面板与隐藏dialog不算阻塞授权；无头V匿名验证不依赖聊天编辑器。
