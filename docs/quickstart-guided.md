# 分步配置

以下用于 v0.4.6 Windows 内置核心；Android 暂停更新。

所有来源共用工作台顶部的一个 URL 和客户端 Key。首次从 EXE 打开时会自动连接新版工作台。

## 第 1 步：软件准备

在工作台点击所需来源的「接入」。窗口只显示当前步骤，点击「一键接入 · 开始准备」。软件准备内置核心与本地配置，不会把来源提前当作已授权。

完整 Windows 构建不需要 Node/Python 或上游程序。准备步骤不下载组件，也不自动启用来源。

## 第 2 步：按当前来源完成授权

- **快速V**：本步有 Google 官方 Express Mode 入口。创建或查看你有权使用的 **Express API Key**，复制并粘贴到本步输入框，再点「保存 Key，下一步」。空 Key 不能继续。
- **无头V**：匿名接口，无需 Google 账号、Cookie 或 Express Key。Windows 准备后自动在当前 Edge / Chrome 建立匿名连接，首次须加载 EXE 自带的连接扩展；浏览器提供官方验证环境。网络与匿名验证失败会分别提示，不要求重新登录账号。真实推理仍待验收。
- **Codex**：本步显示设备码和官方授权入口；本人完成授权后返回，也可导入自己的授权文件。
- **OpenCode**：只展示审阅免费清单与实时目录的交集，无需填写 Key。付费、停用和费用不明的模型不展示。遇到 FreeTierError 是服务方限制免费层客户端，请使用官方 OpenCode；MIXED 不会切换收费模型。
- **WorkBuddy**：先选国内站、国际 WorkBuddy AI 或国际 CodeBuddy，再通过本步官方入口本人登录。三个站点分别保存账号、刷新授权和候选模型，不要求启动另一个客户端。切站后须使用该站自己的账号，国际站也不保证免封。
- **AIS**：本步在当前默认 Edge / Chrome 通过内置扩展打开官方页面；本人登录后软件自动初始化，无需再点击连接会话。Build 和 Playground 分别选择模型，使用测试对话验证 MIXED 实际请求。Android 仍使用隔离系统 WebView。

WorkBuddy检查模型时读取当前站点实时目录，显示当前零积分、积分倍率或费用未声明。国际WorkBuddy AI的DeepSeek V4.1 Flash只在目录确实声明零倍率时标零积分；活动可能随时改变，刷新后重新读取。目录失败直接报错，不拿旧快照上的免费活动替代。

授权说明、获取入口和输入框均在当前配置步骤中，无需跳出去翻总说明。要修改之前的配置，点「返回上一步」。

## 第 3 步：验证并使用

用户确认后才激活连接。点击「检查模型」；失败会停留在相应步骤并给出原因，空列表或读取失败不能报成功。

成功后复制本页的统一地址、客户端 Key 和所选模型 ID 到客户端。再发送一条消息，验证当前模型实际推理权限。后台「诊断」显示最近错误，不保存聊天正文。

## 后台管理

点击左侧「后台管理」，或在本机打开 `/admin`。后台管理内置来源、请求设置，并解释快速V／无头V参数的用途：最多等多少秒、生成前收到限流或繁忙响应后再试几次、回复逐字显示还是全部生成后显示。内部连接地址仅在明确展开的已有服务高级设置中出现，不是填给 AI 客户端的另一套 URL。

Android 使用同一份响应式界面。AIS/无头V需要系统 WebView 支持隔离来源会话；其余来源可按「电脑 MIXED-API」步骤连接电脑。手机客户端仍只使用手机自己的统一地址。真实账号和设备验收状态见 integration-progress.md。

## Windows 浏览器连接

在 AIS 或无头V 的授权步骤点击“打开官方页面”，已加载连接组件时，当前默认浏览器会在同一标签页进入官方页面；未加载时显示首次连接指引。首次在 `edge://extensions`（Chrome 为 `chrome://extensions`）打开开发人员模式，加载该页列出的 `browser-extension` 文件夹，回连接页刷新。扩展随 EXE 提供，无需下载上游。升级后在扩展页刷新“MIXED 浏览器连接”，回软件重新点击“打开官方页面”。不要关闭扩展打开的来源标签页，也不要在该标签页同时手动聊天。短暂连接中断会保留官方页面并有限重连；持续断开后在配置中重新打开。升级EXE后须在扩展页刷新“MIXED 浏览器连接”，旧后台脚本不会自行更新。

本人完成官方登录、条款或验证后，MIXED会自动连接；下一步按钮在会话就绪后可用。无需手动发初始化测试消息。无头V不需要找到聊天输入框或清空草稿才能检查匿名验证。普通帮助面板不会当作授权弹窗；若提示阻塞窗口，按官方页面完成本人操作。Google 的地区、权限或浏览器政策仍由 Google 决定，连接会话成功与真实生成成功分开报告。

AIS v0.4.6通过受控标签的网络规则阻止初始化生成。升级后须刷新扩展，使新增的RPC域名及网络拦截权限生效，再从软件重新打开官方页面。初始化捕获到所需服务后立即停止，不等待模型思考；Build与Playground仍分别路由，不自动换通道或账号。

## 快速V代理与区域

先启动代理软件并开启系统代理，再接入快速V；默认按 PROXY_URL、HTTP(S)环境代理、Windows系统设置选择出口。设置 → 出站代理可以查看当前快速V出口、填写 HTTP/HTTPS/SOCKS5 地址或明确选择直连。本机统一 API 地址仍为 `http://127.0.0.1:8765/v1`。请勿填写订阅链接。系统设置最长5秒刷新，点“读取设置”立即刷新。PAC未返回代理时会停止，请手动选择可用代理或直连。

AIS与无头V由浏览器发送请求，使用浏览器自己的代理；MIXED手动代理不会改动Edge。快速V保存Key时自动探测绑定项目并填写global；更换Key会重新探测。探测失败可在Key步骤展开项目/区域，填写该Key所属项目和模型支持区域；两项须同时填写。404仍需核对模型ID与访问权限。生成前429/502/503及未交付内容前的断流默认最多重试2次，总时限300秒，可在后台调整。完整缓存模式在成功生成全部候选后交付，失败尝试不泄露半段内容；已交付的流不自动重新生成。明确内容拦截、401/403不重试，429检查额度或限流。TLS证书错误应检查系统时间和受信任证书；没有关闭证书验证的开关。

Gemini 4 Argon 使用 `vertex/gemini-4-argon`，支持low/medium/high思考档；minimal会在本地拒绝。出现在目录不代表当前Express Key有额度，404和429须查看后台实际状态，不能据单次错误删除模型。

## 快速V断线续传（可选）

后台开启“客户端断线续传”后，关闭客户端连接不会停止生成；默认关闭时保持随断开取消。启用后，客户端保存响应头 `X-Mixed-Stream-ID`，使用相同客户端Key访问：

- `GET /v1/resumable/{id}?from=0&limit=128&wait=25`：读取JSON事件，按返回的next继续；done表示任务结束，status区分done/error/cancelled。
- `GET /v1/resumable/{id}`，带 `Accept: text/event-stream` 和 `Last-Event-ID`：读取其后的SSE事件；也可使用resume_from指定下一条序号。
- `DELETE /v1/resumable/{id}`：主动停止生成。

需要通过POST重连时，首次和重连都传相同 `Idempotency-Key` 与完全相同的请求内容；同一键不同内容返回409，无键POST各自产生新回复。仅限 `/v1/chat/completions` 的快速V流。此功能需要客户端配合，不会自动修复不支持续传的客户端。单回复8MB，总64MB、最多32条，完成后默认保留300秒（30–1800可调）；缓冲满返回明确错误。软件退出、缓存过期或更换客户端Key后无法读取旧缓冲。它不等于上游断流续写，也不包含Gemini长解码continuation token。

## WorkBuddy积分

实际请求消耗对应站点账号的积分。积分不足时，到WorkBuddy/CodeBuddy官方账号用量页查看剩余额度、恢复时间及官方补充选项；等待恢复或按本人意愿购买额度后重试。重新授权仅修复登录过期，刷新令牌和刷新模型不会补积分。国内与国际站的账号和额度分开计算，不能互相替代。后台记录HTTP状态与安全的业务错误码，不能将所有403或429都当成积分不足。
