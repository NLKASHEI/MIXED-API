# MIXED-API · 逐步确认的新手向导（Windows）

**主界面就是软件窗口，不需要手动打开网页后台。** 左侧六个来源，右侧只显示当前来源的下一步。软件自动完成下载、创建本地 Key、安装和启动，**账号授权必须由你本人确认**。

## 真实操作顺序

1. **点击来源的「一键接入」**：软件进入 **① 自动准备**。等待安装运行时、部署、启动。此时「下一步」不可点击；若缺少 Node/Python，程序会提示先完成系统运行时安装，并重启 MIXED-API。
2. **停在「② 请完成授权或确认」**：程序在需要时自动打开官方网页或登录窗口，右侧说明你该做什么。
   - **Codex**：通过 Codex CLI 打开 ChatGPT 官方账号授权；完成后回到 MIXED-API。不需要 SillyTavern，也不需要复制 OAuth Token。
   - **Vertex Express**：若缺少 Key，会打开 Google 官方 Express Mode 页面。申请并复制自己的 **Express API Key**，在右侧输入，点「保存并继续」。它不是 MIXED-API 的客户端 Key。
   - **OpenCode**：可先试匿名模式；如果后台需要 Zen 授权，则可打开 OpenCode Zen 页面，填写自己的 Zen Key。
   - **WorkBuddy**：在官方 WorkBuddy 桌面客户端登录；如检测到需要授权，软件可打开其官方网站。官网页面不能替代桌面客户端本身的登录。
   - **APS2api**：阅读、理解并确认原项目非商业许可和使用规则，无需手工生成本地 API Key。
   - **AI Studio Build**：首次会打开原项目的 Camoufox/Google AI Studio 授权窗口；在官方页面本人登录，软件复用已有的有效会话。不会模拟登录或替你获取 Cookie。
3. **只有做完后才点击「我已完成，下一步」**：软件才正式进入 **③ 检查模型**，验证当前上游授权状态和统一模型列表。如果仍提示未登录、HTTP 401/403 或没有模型，软件**退回第②步**，解释原因；绝不因进程启动、按钮点击或定时刷新而自动标记完成。
4. **看到「已验证模型列表」**：选择模型下拉框并点「复制模型 ID」。再点顶部「复制 API 地址」「复制客户端 Key」，在任意 OpenAI 兼容客户端分别填写：
   - Base URL: `http://127.0.0.1:8765/v1`
   - API Key: 软件自动生成的 **MIXED-API 客户端 Key**
   - Model: 软件实际列出的完整模型 ID，如 `codex/...`、`vertex/...`。

**注意：读取到模型列表只能证明模型枚举接口可用，不能保证实际聊天一定成功。** 发起真实请求后，在窗口底部的「请求日志」查看状态码和错误原因。不会保存正常聊天正文。

## 登录窗口没弹出怎么办？

停留在第②步，点击右下的「打开登录窗口」或「申请 Express Key」等按钮再试；这不会自动跳过本人确认。Windows 浏览器必须能访问对应官方站点，Camoufox 也需要下载依赖。没有账号授权或上游配额时，MIXED-API 无法替用户绕过平台限制。

## 我点击下一步但失败了？

你会留在 **第②步**，看到本次模型检查失败原因。确认官网登录完成、所填的是上游官方 Key 而非本地 Key、原服务未退出，然后再点同一个「我已完成，下一步」。若 Windows 新安装了系统 Node/Python 运行环境，则关闭、重开 MIXED-API，再点击「重新接入」。

## 不小心选错来源？

切换左侧来源即可，其他来源的引导进度与已发现模型会保留在本次运行的内存中。重启程序后需要重新点击来源以继续向导，**不会删除已经保存的 API Key 或第三方登录会话**。用户授权信息不由向导伪造。

## Android

Android APK 保留轻量原生界面，暂无 Windows 版这种完整逐步确认向导。Codex CLI、WorkBuddy 客户端和 Camoufox 这些桌面进程仍需要 Windows 电脑运行，可通过手机与电脑的 LAN API 桥接模型。
