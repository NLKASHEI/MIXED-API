# MIXED-API 新手引导 · 一键接入后下一步做什么？

从 v0.2.21 起，Windows 软件默认显示「**左侧六个来源 + 右侧动态操作引导 + 底部精简请求日志**」。用户不需要打开浏览器后台、修改原项目 JSON，或自己填本地代理地址。

## 只要四步

1. **选来源**：在左侧点击你想使用的来源（例如 Codex）的「接入」按钮；MIXED-API 自动下载安装环境、生成本地服务 Key、启用代理并检查模型。右侧会持续显示真实状态，而不是点完就提示成功。
2. **完成必须由本人做的事**：右侧会提示「等待账号授权」「需要官方 Key」或「缺少运行时」。需要授权就点击「打开登录窗口」，用自己的账号在官方窗口操作；Vertex Express 和 OpenCode Zen 的 Key 可以直接粘贴在软件窗口里。**不需要填写 MIXED-API 生成的本地上游 Key。**
3. **确认模型可用**：点击「检查模型」；右侧出现真实的完整模型 ID（如 `codex/gpt-...`）才意味着模型已接入。若模型为空，查看右侧说明和底部简短错误日志，不能把「进程启动」当作成功。
4. **提供给自己的 AI 应用**：点击顶部「复制 API 地址」与「复制客户端 Key」，将 `http://127.0.0.1:8765/v1` 和该 Key 填进任意 OpenAI 兼容客户端。选择右侧模型下拉框中的模型，点击「复制模型 ID」，粘贴到客户端模型位置即可。

## 六个来源的差别

| 来源 | 软件自动完成 | 人需要做的事 |
| --- | --- | --- |
| Codex | 安装 CLI，连接 app-server，检查模型 | 首次使用 ChatGPT 官方授权；**不需要 SillyTavern** |
| Vertex · Gemini | 配置 Python 代理、随机本地 Key、启动服务 | 有 Express Key 时粘贴到右侧输入框；没有则先申请（原项目 Cookie 直连等高级方式不属于免授权） |
| OpenCode | 自动下载已编译代理，设置本地 server key | 可尝试匿名模式；需 Zen 模型时填写 Zen Key，不要填本地 server key |
| WorkBuddy | 安装/运行代理并查找客户端 | 电脑需要官方 WorkBuddy 客户端并且已经登录 |
| APS2api | 下载固定版本、配置 Key、启动 | 确认遵守原项目非商业许可证和上游规则；匿名接口不保证可用 |
| AI Studio Build | 下载源码、准备 Node/Camoufox 环境、运行代理 | 首次本人在 Google AI Studio 的浏览器窗口登录；已有有效会话可复用 |

## 状态说明及下一步

- **尚未接入**：点击来源旁「接入」。
- **正在自动处理 / 正在验证**：软件还在准备或检查；无需重复点击。
- **等待账号授权**：完成官方窗口登录；返回软件点击「检查模型」。
- **待重启软件**：已尝试安装 Node.js/Python，重启 MIXED-API 使新的环境变量生效，再接入同一来源。
- **已授权，待检查模型**：登录并不等于能聊天，点击「检查模型」。
- **模型已就绪**：复制 Base URL、客户端 Key、模型 ID 即可使用。
- **连接失败**：阅读右侧原因、下方请求错误，按对应建议排查，然后点击「重新接入」。

**Windows 是原生 Win32 软件窗口**。旧的 `http://127.0.0.1:8765` 网页后台只作为可选高级入口；`/v1` 仍然在后台提供接口给各种 AI 客户端。底部日志仅保留有限条请求元数据和简短错误，不保存聊天正文。Android APK 依然是轻量原生控制页，桌面专属 Codex/WorkBuddy 后端只能通过电脑的 LAN 8766 桥接给手机；详情见仓库 `docs/quickstart-zh.md`。
