# 按每一步接入，不需要认识内部端口

所有来源共用工作台顶部的一个 URL 和客户端 Key。首次从 EXE 打开时会自动连接新版工作台。

## 第 1 步：软件准备

在工作台点击所需来源的「接入」。窗口只显示当前步骤，点击「一键接入 · 开始准备」。软件准备组件与本地通信配置，不会把来源提前当作已授权。

新装 Node/Python 后 Windows 可能尚未刷新运行环境，界面会提示完成安装并重开 MIXED；再次从第 1 步继续，配置会保留。

## 第 2 步：按当前来源完成授权

- **快速V**：本步有 Google 官方 Express Mode 入口。创建或查看你有权使用的 **Express API Key**，复制并粘贴到本步输入框，再点「保存 Key，下一步」。空 Key 不能继续。
- **无头V**：点「打开无头V确认窗口」，在组件窗口本人阅读并确认使用规则，保持服务运行后返回下一步。这里不填 Express Key，不选程序版本。
- **Codex**：本步打开官方 ChatGPT 登录窗口；本人完成授权后返回。不复制 Token。
- **OpenCode**：可选填写自己的 Zen Key；留空会尝试其匿名模式，是否可用由上游决定。
- **WorkBuddy**：在官方桌面客户端本人登录并保持运行，网站登录不能代替客户端登录。
- **AI Studio**：本步打开 Camoufox 登录窗口；本人完成 Google AI Studio 登录后返回。

授权说明、获取入口和输入框均在当前配置步骤中，无需跳出去翻总说明。要修改之前的配置，点「返回上一步」。

## 第 3 步：验证并使用

用户确认后才激活连接。点击「检查模型」；失败会停留在相应步骤并给出原因，空列表或读取失败不能报成功。

成功后复制本页的统一地址、客户端 Key 和所选模型 ID 到客户端。再发送一条消息，验证当前模型实际推理权限。后台「诊断」显示最近错误，不保存聊天正文。

## 后台管理

点击左侧「后台管理」，或在本机打开 `/admin`。后台管理受管进程、来源配置，并解释无头V参数的用途：最多等多少秒、失败后再试几次、回复逐字显示还是全部生成后显示。内部连接地址仅在明确展开的已有服务高级设置中出现，不是填给 AI 客户端的另一套 URL。

Android 使用同一份响应式界面。手机无法执行桌面组件，推荐按「电脑 MIXED-API」卡片中的步骤连接电脑；手机客户端仍只使用手机自己的统一地址。
