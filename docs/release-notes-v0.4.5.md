# MIXED-API v0.4.5

- AIS 先检查当前浏览器已有账号的模型目录，区分账号登录、地区权限、网络和协议材料加载；不再把这些状态统一写成人机验证。已捕获有效协议材料时不要求额外发送初始化消息。
- 无头V在官方页面缺少 SDK 时加载官方 reCAPTCHA Enterprise 脚本，不依赖聊天输入框。真正的登录、条款和挑战仍由本人处理。
- WorkBuddy 授权步骤增加国内站、国际 WorkBuddy AI、国际 CodeBuddy，分别使用对应站点、产品标识、账号文件和刷新流程。切站不串用令牌。国际站不保证免封，积分仍由各站账号管理。
- 恢复快速V的 `vertex/gemini-4-argon`，使用 `v1beta1`，拒绝该模型不支持的 minimal 思考参数。模型列出不代表当前 Key 有权限或额度。
- 快速V支持交付前断流重试；开启“完整缓存后交付”时，丢弃未完成尝试，完整成功后再交付。明确的内容拦截不会重试。已经交付的流不重新生成补字。
- 新增可选的客户端断线续传，默认关闭。启用后生成在客户端断开时继续，客户端通过同一次回复的 ID 读取缓冲；主动停止须调用 DELETE。普通相同请求仍独立生成，同一幂等键换请求体返回409。
- 修复续传错误状态及 Retry-After 发布竞态；缓存按读取者保留预算，并对慢连接设置写入时限。后台记录生成结果与重试诊断，不记录聊天正文和凭据。

## 更新和配置

退出旧版，保留 `mixed-api.json`，运行新版 EXE。AIS/无头V重新打开官方页面前，在 `edge://extensions` 或 `chrome://extensions` 刷新“MIXED 浏览器连接”，让当前浏览器使用新版脚本。仍使用用户当前默认 Edge/Chrome 普通配置，不启动独立浏览器配置。

WorkBuddy 在授权步骤先选站点再登录；各站模型列表是候选目录，实际权限以该账号响应为准。积分不足按当前站点官方用量页处理；刷新账号不会补积分。

快速V先配置有效代理，再保存 Express Key。后台可设置重试、完整缓存与断线续传，具体接口见[配置指引](quickstart-guided.md)。完整缓存最多32MB；续传内存缓存单回复8MB、总计64MB、最多32条，完成后默认保留300秒。软件退出或 Key 更换后旧回复不可继续读取。客户端必须支持续传接口才能恢复，不能使所有第三方客户端自动恢复。

## 验收范围

核心回归覆盖三站授权/刷新隔离、已有账号探测、SDK加载、Gemini 4路由、拦截不重试、交付前断流、一次生成多次续读、幂等冲突、原始429和主动取消。个人 Google 账号真实生成尚未验收，不将模拟协议测试写成账号已可用。Gemini 4长解码 continuation token 尚未实现，本版不宣称支持无限续写。

Windows资产由本标签成功的 GitHub Actions 构建；Android继续暂停，不附APK。问题跟踪：[Issue #5](https://github.com/NLKASHEI/MIXED-API/issues/5)。
