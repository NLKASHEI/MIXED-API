📱 Android 如何使用电脑上的 Codex / WorkBuddy？

关键规则：Windows 可以本机调用 Codex CLI、自动发现 WorkBuddy；Android APK 本身只有 HTTP 网关，不能运行 Windows CLI。想让 Android 使用它们，需在 Windows 额外启动仅 API 的局域网共享端口 8766，手机连接这台电脑。电脑的后台和上游 Cookie/令牌不会开放到局域网。
  1. 电脑：关闭现有 MIXED-API，双击 Start-MIXED-API-LAN.cmd。通过 Windows ipconfig 查 Wi-Fi / 以太网 IPv4（通常 192.168.x.x），允许 Windows 防火墙在专用网络下访问 8766 端口。不要启用公网端口映射。
  2. 电脑：启用 Codex / WorkBuddy 等来源，刷新模型。复制本页 客户端 API Key（不是 Admin Key）。
  3. 安卓：在手机 MIXED-API 后台，打开「电脑 MIXED-API」一项，填 http://电脑IPv4:8766/v1，上游 Key 填刚复制的电脑客户端 Key，Auth 选 bearer，启用 → 保存 → 刷新模型。
  4. 任何手机客户端：仍只填 http://127.0.0.1:8765/v1 和手机 MIXED-API 客户端 Key，可见模型保持 codex/gpt-... / workbuddy/...，不会出现多余的 pc/ 前缀。

不同网络或离开家里的 Wi-Fi 后，这种 LAN 连接就会失效。HTTP 在局域网中不加密，请只用可信网络；跨互联网时不要开放 8766，请使用受控的 VPN / 加密隧道。

小白快速上手：只做三件事

  1. 选择想用的来源。无需六个都配置，先接通一个就可以使用。
  2. 打开来源卡片里的“手把手配置向导”。每一步有准确的网址、命令和需要复制的 Key。Windows 端支持部分一键下载、安装及启动。
  3. 启用并保存 → 刷新模型。从列表复制 来源/模型名 到任意支持 OpenAI API 的客户端，填本页统一地址和客户端密钥。
两个密钥不要搞混： 本页的 MIXED-API Key 是你给聊天工具的；每个上游自己的 Key 只填在对应来源里。大多数网页授权必须由你本人登录，程序不能也不会替你读取密码、绕过验证码。
