小白快速上手：只做三件事

  1. 选择想用的来源。无需六个都配置，先接通一个就可以使用。
  2. 打开来源卡片里的“手把手配置向导”。每一步有准确的网址、命令和需要复制的 Key。Windows 端支持部分一键下载、安装及启动。
  3. 启用并保存 → 刷新模型。从列表复制 来源/模型名 到任意支持 OpenAI API 的客户端，填本页统一地址和客户端密钥。
两个密钥不要搞混： 本页的 MIXED-API Key 是你给聊天工具的；每个上游自己的 Key 只填在对应来源里。大多数网页授权必须由你本人登录，程序不能也不会替你读取密码、绕过验证码。
