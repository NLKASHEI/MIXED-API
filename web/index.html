GET STARTED

四步，开始使用。

软件负责准备环境；你的账号，仍由你本人授权。

  1. 选择一个来源

    回到工作台，选择你已有账号或权限的来源。Windows 可自动准备支持的后端；Android 建议连接电脑的 LAN API。

  2. 按提示完成授权

    官方登录、自己的 Express / Zen Key、已登录的桌面客户端。不要把客户端 Key 和上游 Key 混用。

  3. 确认模型，再发一次消息

    点击「我已完成，检查模型」。读到目录之后，在客户端做一次真实请求，才能确认该模型当前可用。

  4. 填入你的 AI 客户端

    Base URL 和客户端 Key 从工作台复制；模型从模型页选择。Cherry Studio、SillyTavern 等支持 OpenAI 兼容接口的客户端均可按其设置填写。

手机连接电脑

电脑运行 Start-MIXED-API-LAN.cmd，手机与电脑连接同一可信 Wi-Fi。在手机的「电脑 MIXED-API」里填写 http://电脑实际IPv4:8766/v1，上游 Key 填电脑客户端 Key。8766 只共享 API，不能管理电脑。

无头V · 请求与等待设置

在这里控制一次请求最多等多久、失败后再试几次，以及回复是逐字显示还是全部生成后显示。只影响无头V。

网络临时失败时重新尝试。次数越多，失败时等待越久，也可能增加上游请求量；建议 1–2 次。

超过这个时间还没完成就停止等待。长回复可设 180 秒或更长。

不勾选：边生成边显示，通常更快看到内容。勾选：等全部生成后一次返回，等待期间可能看不到文字。

管理权限

此后台只在本机管理端口开放，使用独立 Admin Key。客户端 Key 无法更改后台配置，局域网 API 端口不提供后台入口。
