零基础使用指引

不需要先理解“反代”是什么，按顺序完成每一步即可。

查看完整中文文档 ↗

① 先启动 MIXED-API

Windows 直接双击 MIXED-API.exe，自动打开本管理页面。第一次生成两套密钥：Admin Key 用来登录这里，客户端 API Key 用来连接模型。

② 选择一个来源

进入「上游服务」，点击「软件内托管」下的「一键部署」，MIXED-API 自动下载、配置后端。优先点“一键部署”；下载、配置和本地 Key 由 MIXED-API 自动处理。官方账号必要时再授权。

③ 确认模型出现

回到「聚合模型」，刷新成功后出现 来源/模型名。看不到模型时，请在来源卡片中查看“部署状态”和模型错误提示。

④ 在任意客户端使用

接口地址 http://127.0.0.1:8765/v1，Key 为 MIXED-API 客户端 Key；模型填实际复制的完整 ID。不是只能给 SillyTavern 用。

安卓如何连接电脑上的 Codex / WorkBuddy？

电脑与手机同一可信 Wi-Fi： 电脑上启动 Start-MIXED-API-LAN.cmd，通过 ipconfig 查电脑 IPv4；手机 APP 中启用「电脑 MIXED-API」，填 http://电脑IP:8766/v1，上游 Key 填电脑客户端 Key。手机本地 API 地址和 Key 保持原样。电脑的管理后台不会通过 8766 提供，但同一局域网 HTTP 不加密，不能映射公网。

常见问题

0 个模型 / 无法连接？

确认来源服务已启动且能独立获取模型；确认来源 URL 最后是 /v1，不是 /v1/models；检查对应来源的上游 Key，而不是本机客户端 Key。

Key 有三个，到底填哪一个？

Admin Key 登录 MIXED-API 后台；MIXED-API 客户端 Key 给你的聊天软件；上游 Key 填每个来源的卡片里。Codex CLI 使用账号授权，不要求在卡片里粘贴 OAuth Token。

能不登录 Google、WorkBuddy 吗？

首次需要本人完成授权，已保存的合法登录会话可复用。MIXED-API 可以安装依赖并启动登录流程，但不会抓取 Cookie 或绕过验证码。

手机 APK 能原生运行 Codex 吗？

不能把 Windows Codex CLI 或 WorkBuddy 客户端自动变成 Android 原生程序。手机 APP 是独立网关，可以连接已经运行的电脑网关和可访问的 HTTP 上游。

网络与设置

保持私有凭据与管理接口仅在本机，按需使用局域网共享 API。

本地监听地址

http://127.0.0.1:8765

本地网页管理后台、配置和密钥仅在同一台设备访问；无需暴露公网。

可选的电脑局域网 API

http://电脑IPv4:8766/v1

必须用 Start-MIXED-API-LAN.cmd 显式启动，只开放 API。不允许通过此端口管理账号和后端。

凭据管理

Admin Key 与客户端 API Key 不同。请妥善保管 mixed-api.json；不要发给他人、提交 GitHub 或放入共享目录。

源码与许可证

各上游许可证和使用条款独立生效。MIXED-API 不捆绑第三方反代源码和登录凭据。
