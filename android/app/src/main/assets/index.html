先连接电脑上运行的模型

手机 APK 不能直接运行 Windows Codex CLI、WorkBuddy 或 Camoufox。你只需在电脑运行 MIXED-API 的 LAN 模式，手机即可通过它访问已经连接的模型。
  1. 电脑双击 Start-MIXED-API-LAN.cmd，在后台启用并配置上游。
  2. 电脑运行 ipconfig 查看实际的局域网 IPv4。
  3. 在下面「电脑 MIXED-API」卡片填 http://电脑IP:8766/v1 和电脑客户端 Key，启用并保存。
  4. 点「刷新模型」，使用完整模型 ID，如 codex/gpt-...。确保同一可信 Wi-Fi，防火墙允许专用网络 TCP 8766。

不要把电脑 Admin Key 填给手机；请勿将 8766 暴露至公网。
